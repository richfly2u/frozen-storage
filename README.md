# ❄️ 佛堂冷凍庫 物品位置管理

掃碼即用的冷凍庫物品位置圖，支援線上新增／修改／移出／刪除，資料即時同步到所有手機與電腦。

- 網址：<https://richfly2u.github.io/frozen-storage/>
- 免帳號、免密碼：開啟即自動連線，掃 QR 直接跳到指定層。

## 四層配置

| 樓層 | 位置 | 區域 |
| --- | --- | --- |
| 第 1 層 | 上門・上層 | 中藥區 |
| 第 2 層 | 上門・下層 | 素料、餡料區 |
| 第 3 層 | 下門・上層 | 素料 |
| 第 4 層 | 下門・下層 | 其他 |

## 使用方式

1. **第一次先設定經手人**：頁面上方「經手人：未設定」→ 按「修改」輸入姓名（例如「陳師姐」）。設定後每次操作都會自動帶入。
2. **登錄物品**：位置圖頁按「＋ 新增物品」→ 填品名、數量、單位、樓層、經手人（可加備註）。
3. **移出／置入**：點該物品 → 用 −／＋ 調整數量 → 儲存（自動記一筆「移出／置入」，含經手人）。
4. **刪除**：點物品 → 按「刪除」（會二次確認，並保留含經手人的刪除紀錄）。
5. **搜尋**：頂端搜尋框打品名（例：當歸），會標出黃框並顯示位於哪一層。
6. **貼 QR**：切到「QR列印」→ 列印後貼在各層門邊。手機用 **LINE 掃碼** 會開啟 `?f=1`～`?f=4`，直接定位到該層並閃框提示。
7. **查紀錄**：切到「紀錄」看置入／移出／新增／刪除，每筆都有**經手人**，可用下拉篩選某人做過什麼。

## 經手人（放入者）紀錄

- 位置圖的每個品項會顯示 `👤姓名`（最後一次放入／調整的人）。
- `紀錄`頁每筆都有 `👤姓名`，並可從上方下拉只顯示某人的紀錄。
- 姓名記在該手機／電腦的本機（`localStorage`），換人操作時按「修改」即可切換。
- 資料欄位：`frozen_items.by`、`frozen_log.by`。

## 用 LINE 掃碼

- QR 內容就是本頁網址（`https://richfly2u.github.io/frozen-storage/?f=N`），LINE 內建掃碼器可直接開。
- 在 LINE 內建瀏覽器開啟時，頁面上方會出現提示；若按了沒反應，點右上角「⋯」→ 用其他瀏覽器開啟即可。


## 技術備註

- 前端：單檔 `index.html`（Firebase JS SDK 10.12.2，QR 為內嵌 SVG），無建置步驟。
- 資料：Firestore 專案 `bentodish-alan`，集合 `frozen_items`（物品）、`frozen_log`（進出紀錄）。
- 權限：需匿名登入（頁面自動處理）；`frozen_log` 不可修改，只有管理員可刪。
- 換 Firebase 金鑰／專案：改 `index.html` 裡 `window.FIREBASE_CONFIG`。
- 改樓層名稱：改 `index.html` 裡的 `FLOORS` 陣列。
- **換網址或改樓層名稱後，QR 要重產**：`pip install segno` 後執行 `python _probe/make_qr.py`（QR 是內嵌向量圖，不依賴外部 CDN）。
