# ❄️ 凱德佛堂 冷凍庫 物品位置管理

冷凍庫物品位置圖（含語音輸入），支援線上新增／修改／移出／刪除，資料即時同步到所有手機與電腦。

- 網址：<https://richfly2u.github.io/frozen-storage/>
- 免帳號、免密碼：開啟即自動連線，可直接使用。

## 樓層配置

**每扇門各自從第1層算起**（上門＝第1、2、3層；下門＝第1、2層），門名（上門／下門）以**直排門牌貼在門的右緣（原本把手的位置）**，把手已移除。

| 畫面顯示 | 所在門 | 區域 |
| --- | --- | --- |
| 第1層 | 上門 | 中藥區、甜餡料、湯料 |
| 第2層 | 上門 | 素料 |
| 第3層 | 上門 | 素料 |
| 第1層 | 下門 | 素料 |
| 第2層 | 下門 | 其他 |

位置圖以**商用不鏽鋼雙門冰櫃**呈現（上下兩扇玻璃門，上門藍色系、下門綠色系）。每層空間比例為 **高:寬 = 3:4**。
**每扇門最下層的橫槓切齊門的底緣**（下門最下層＝貼住冰箱底）；冰箱頂的散熱柵與 -18°C 溫控面板、門把、輪子都已移除（省高度）。
層數（第N層）寫在該層橫槓的正中間；下拉選單／提示訊息會帶門名（例如「下門 第1層 素料」）以免兩門混淆。

> 要改層數或名稱：改 `index.html` 的 `FLOORS` 陣列即可（層數／格位自動算，畫面編號按各門自動計算）。
> 新增樓層請給「沒用過的 id」（例如再加一層用 6），**不要改舊 id**，否則既有物品會跑錯位置。

### 數量顯示規則
- **只寫品名** ＝ 還有 1 包（大部分品項都是 1 包，不另外標數字）。
- **寫數字** ＝ 2 包以上才標（例：`5 包`）。
- **數量 0（用完）不顯示** ＝ 位置圖只列冰箱裡還有的東西，用完的不會出現（該品項會出現在右邊食材庫）；說「**放回 ○○ 一包**」或用拖曳即可補回並重新出現。

## 頁面

**只有一頁：位置圖**（含語音輸入）。「紀錄」頁與底部那條「位置圖／紀錄」分頁列都已移除（前賢確認不需要紀錄），冰箱因此再長高約 60px。

## 經手人（第一次用會問一次，之後就記住）

- **任何人第一次要操作（拖曳／點物品／語音）時，會先跳出「請先輸入經手人姓名」**，填一次就記在該台裝置（`localStorage`），**以後不再問**。
- 還沒填時，最上方「經手人」名牌會**閃黃色**提醒；填過就恢復正常，可隨時按「修改」改名字。
- 貨是誰放的／誰拿的，都會記在這個名字上（方框上的 👤 預設隱藏，可由最上方「顯示經手人」開關打開）。
- 原本規劃的「LINE 掃碼自動帶入姓名」已移除（前賢：有經手人就夠了）。

## 語音（浮動的「開始聽」）

- 「🎤 開始聽」是**浮動鈕**（桌機在左下角、手機在右下角），不佔用版面。
- **進網頁時是「未開始」狀態，麥克風不會啟動**；一定要按「🎤 開始聽」才會開始聽（按鈕會變紅色「⏹ 停止聽取」、狀態列變粉紅底「聽取中…」），再按同一顆鈕就是停止。
- 開始聽之後講「香菇頭 一包」「移出素排骨兩袋」「放回當歸五包」→ 出現確認卡按 ✅ 確認。沒講動作＝預設「移出」。
- 第一次使用要按瀏覽器「允許」麥克風。

## 冰箱裡的東西怎麼呈現

- 每一層的物品用**方框**呈現（跟食材庫一樣），**多列排開**（桌機一層約可放 11~13 個、手機約 2~3 個一列），**盡量一頁看到最多的東西**。
- 方框上**只寫品名**（不顯示數量、斤數、經手人，也沒有 ⋯ 點點）→ 畫面最乾淨。
- **點一下＝編輯**（數量／單位／樓層／經手人／備註／改名／刪除都在編輯視窗裡）。
- **長按約 0.25 秒＝移動**，此時浮動標籤會**顯示細節**（品名＋數量＋經手人），拖到目標層放開即可；沒長按直接滑＝捲動頁面。
- 層名（例：中藥區、甜餡料、湯料）用**小字、同一列不換行**；**每層有幾項不顯示**，畫面上就是單純「層名＋品項名稱」。
- **同一層的品項順序固定**：按「加入冰箱的先後」排（舊的在前、剛加入的在最後）。移過去、改名字都不會讓它跳到那一層的第一位。
- 點／長按品項**不會再跳出「複製、全選」的小選單**（已關閉網頁的文字選取；輸入框仍可正常輸入）。
- **放進冰箱後會提示**：那一層用**綠色框**框起來、剛放進去的那樣食材用**橘色框**框起來，**3 秒後自動恢復**。
- 手機版「開始聽」在**食材庫的下方（方框外面）**，不擋冰箱也不擋食材庫。
- 手機版**冰箱與食材庫一定同在一頁**：頁面本身不捲動；食材庫若裝不下（東西很多），**在食材庫自己裡面捲動**。
- 最上方「顯示經手人」是**亮黃色**（深色底、對比 9:1，深藍標題列上看得清楚）。
- 食材庫的格子**文字與框貼緊**（上下不多留白），一頁可放更多樣。
- 拖曳時**不會出現任何動態提示**（不會標示拖到第幾層、不會變色放大），放手就定位。
- 手機版**上門與下門一樣高**（兩扇門等高，層數少的門每層會比較高）。

## 食材庫（右欄）

- **緊湊方格**：食材庫用緊湊方格（桌機 58×40、每列 5 格；手機 60×38、每列 6 格），4 個字的名稱會自動換成兩行、不會被切；食材變多時**食材庫自己內部捲動**（不會把整個頁面撐長）。
- **常備食材**：內建 25 樣常用食材（當歸、枸杞、紅棗、豆包、麵腸、火腿、素丸子、牛蒡排、鱈魚排、飯巾布、麵線、饅頭、包子、綠豆沙餡、小魚干、紅糟麵腸、黑豆、花生仁、大薏仁、豆干、大胖干、核桃、腰果、海帶芽、味噌）。**冰箱裡已經有的就不會重複列出**；把食材庫的項目**拖進冰箱任一層**＝放進冰箱（自動建檔，記一筆「新增」）。
- **冰箱裡沒有的**：數量 0（用完／已移出）的品項（格子底色不同），**拖回冰箱任一層**＝放回。
- 桌機 5 格一列、手機 6 格一列；目前 22 樣全部顯示得下、不用捲（手機也一屏看完），品項再增加就在食材庫內捲動。
- 要改內建常備清單：改 `index.html` 最上面設定區的 `STAPLES` 陣列（一行一個名字）。
- 「清暫存」只清掉剛拖出來的那份暫存，不影響庫存與紀錄。

## 手機怎麼用（螢幕小，特別設計）

手機版由上到下：**最上方一列＝標題＋搜尋＋經手人 → 冰箱（上門、下門左右並排）→ 食材庫（緊接冰箱下方、格子多列排開）→ 顯示經手人開關**；浮動語音鈕在右下角。

- **把冰箱裡的東西搬到別層**：手指**按住約 0.25 秒**（會震一下）就進入拖曳，接著往任何方向拖到目標層放開即可（上下門互換也可以）。
  沒按住直接滑＝正常捲動頁面，所以不會誤搬。
- **把食材庫的東西放進冰箱**：① 拖進冰箱任一層；或 ② **點一下**食材（綠框）→ 再**點想放的那一層**（每層會出現綠框）。
- 冰箱裡的東西也可以：點它改數量、點 **⋯** 改名／移到別層／刪除。

## 版面（便當組合模式）

- 桌機／平板採**兩欄**：**左＝冰箱（吃滿寬度）**、**右＝食材庫（330px）**；**最上方一列＝標題＋經手人＋顯示經手人開關**（橫向）。已無搜尋框（前賢：搜尋不用了）。
- 冰箱上方只留標題列，其餘文字全部收掉 → **冰箱吃滿高度與寬度，整個畫面一頁看完**（實測 1200×860、1366×768 頁高＝視窗高，一頁剛好）。
- 筆電矮螢幕（高度 ≤820px）自動把層距收窄，把空間讓給層架。
- 手機：**最上方就只有一列＝「❄️ 凱德冷凍庫」＋經手人（👤名牌＋修改）＋顯示開關**（不多佔高度，實測 header 36px）→ **冰箱（上門、下門左右並排）** → **食材庫（冰箱正下方、方格多列）**；浮動語音鈕在右下角。整頁一屏看完（430×900、390×844 實測頁高＝視窗高）。

## 就地操作（像便當組合那樣直接拖）

| 想做的事 | 怎麼做 |
| --- | --- |
| 改數量／備註 | **點一下**物品 → 改數量 → 儲存 |
| **移出冰箱** | 把物品**拖出去**：拖到右邊「📦 食材庫」，或拖曳時畫面下方浮出的「📤 放這裡＝移出冰箱」 |
| **放回冰箱** | 把「📦 食材庫」裡的東西**拖回**任何一層，放手即放回（順便決定放哪一層） |
| 搬到別層 | 直接把物品**拖到**那一層（拖曳時該層亮綠框）；也可以用 ⋯ → 📦 移到 |
| 改名字 | 點物品上的 **⋯** → ✏️ 修改名稱 |
| 刪除 | 點物品上的 **⋯** → 🗑️ 刪除（會二次確認） |

- 桌機用滑鼠直接拖；手機／平板手指要**橫著起手**（直的滑＝捲動頁面）。
- 拖曳時靠近畫面上／下邊緣會自動捲動。
- **食材庫**＝「冰箱裡沒有的東西」：剛拖出來的 ＋ 用完的（數量 0），重整後也還在，可以隨時拖回冰箱。
- 「清暫存」只清掉剛拖出來的那份暫存；冰箱裡本來就沒有的（用完的）不會被清掉，庫存與紀錄也不受影響。
- 移出／放回／移動／改名／刪除都會留紀錄（含經手人）。

## 使用方式

1. **第一次先設定經手人**：頁面上方「經手人：未設定」→ 按「修改」輸入姓名（例如「陳師姐」）。設定後每次操作都會自動帶入。
2. **登錄物品**：位置圖頁按「＋ 新增物品」→ 填品名、數量、單位、樓層、經手人（可加備註）。**也可以用講的**：按視窗裡的「🎤 用說的」，講「香菇頭兩包」，品名／數量／單位／樓層自動填好，再按儲存。
3. **移出／置入**：點該物品 → 用 −／＋ 調整數量 → 儲存（自動記一筆「移出／置入」，含經手人）。
4. **搬樓層**：直接拖過去，或用 ⋯ → 📦 移到。
5. **刪除／改名**：點物品上的 ⋯。
6. **搜尋**：頂端搜尋框打品名（例：當歸），會標出黃框並顯示位於哪一層。
7. **查紀錄**：切到「紀錄」看置入／移出／新增／刪除／移動／改名，每筆都有**經手人**，可用下拉篩選某人做過什麼。

## 經手人（放入者）紀錄

- **預設不會顯示經手人**：左欄有一個「👤 顯示經手人」開關，勾選才會在物品卡片上顯示 `👤姓名`（選擇會記在該台裝置，下次開啟仍照上次設定）。
- `紀錄`頁每筆都有 `👤姓名`，並可從上方下拉只顯示某人的紀錄（查誰做過什麼用）。
- 姓名記在該手機／電腦的本機（`localStorage`），換人操作時按「修改」即可切換。
- 資料欄位：`frozen_items.by`、`frozen_log.by`。

## 語音輸入（與位置圖同一頁，免打字）

門邊放一台 Android 手機／平板（Chrome），開本頁即可（語音列就在位置圖上方）：

1. 按「🎤 開始聽」（第一次要按「允許」麥克風）
2. 講一句：`香菇頭 一包`　`移出素排骨兩袋`　`放回當歸五包`　`中藥區 當歸 一包`
3. 螢幕出現**確認卡**（動作、品名、數量、庫存變化、經手人）→ 按「✅ 確認」才寫入

- 沒講動作 → 預設「移出」；講「放回／補／置入／進貨」→ 置入。
- 講「**我是陳師姐**」可直接帶入經手人；說「**停止**」停止聽取。
- 講完按「確認」後，畫面會**自動捲到該層、把該層框起來、品項閃一下**，直接就看到更新結果。
- 講到沒建過的品名 → 卡片會問要不要新增（按了直接開新增視窗、欄位已填好）。
- 平板建議：接電源、系統設定「螢幕不關」，開頁後按開始聽即可長掛。
- 解析引擎：`voice-parse.js`（純函式、可單元測試）。測試：`node _probe/test_voice.mjs`。
- 限制：需 **Android Chrome**（iOS Safari 的語音辨識不穩）；環境太吵會辨識錯誤，講錯按「取消」重講即可。

## LINE 掃碼登入（已內建、待填 LIFF ID）

- 頁面已內建 **LIFF（LINE 登入）**：在 LINE 內開啟時自動取得 LINE 名稱，直接帶入「經手人」，不必手打姓名。
- **目前尚未啟用**：`index.html` 裡的 `LIFF_ID` 目前是空字串。沒填＝完全不載入任何外部程式，行為與現在完全相同。
- 取得 LIFF ID（用前賢的 LINE Developers 帳號，約 3 分鐘）：
  1. LINE Developers Console → 建立或選一個 **LINE Login channel**
  2. 該 channel → 左側 **LIFF** → Add → Size: `Full`、Endpoint URL: `https://richfly2u.github.io/frozen-storage/`
  3. 複製 **LIFF ID**（像 `2001234567-abcdefgh`）填進 `index.html` 的 `LIFF_ID`，重新部署即生效
- 桌機（非 LINE 內）開啟時會出現「🔑 用 LINE 登入」按鈕，按了才導去 LINE 授權。

## 技術備註

- 前端：單檔 `index.html`（Firebase JS SDK 10.12.2），無建置步驟、無外部 CDN 依賴。
- 資料：Firestore 專案 `bentodish-alan`，集合 `frozen_items`（物品）、`frozen_log`（進出紀錄）。
- 權限：需匿名登入（頁面自動處理）；`frozen_log` 不可修改，只有管理員可刪。
- 換 Firebase 金鑰／專案：改 `index.html` 裡 `window.FIREBASE_CONFIG`。
- 改樓層名稱／門別色系：改 `index.html` 裡的 `FLOORS` 陣列與 `.door[data-door=...]` 樣式。
- 舊版 QR 貼紙功能已於 2026-10-04 移除（前賢確認不需要），檔案因此縮小約 8KB。
